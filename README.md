# Testbed sample

A small repository for testing Testbed's GitHub connection, issue import, and reproduction flow.

Run the example with Python 3:

```sh
python3 main.py
```

The example reads `items.json` and prints a count of open and closed items.
For the current fixture, the output is `Counter({'open': 2, 'closed': 1})`.

This repository also serves as a small push-event fixture for Testbed automation checks.
